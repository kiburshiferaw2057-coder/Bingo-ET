# Bingo ET Android prototype

A free-to-play Bingo practice app in English and Amharic.

## Included
- 5-column B I N G O cards using numbers 1–75
- One-line, three-line and four-corner-star modes
- Automatic number draw and automatic marking of called numbers
- Manual marking for practice
- Multiple cards (up to 10 in this prototype)
- Local practice points and winner confirmation

## Build
Open this folder in Android Studio and run the `app` configuration, or use the included GitHub Actions workflow.

## Important limitations
This is a local prototype, not a production multiplayer service. The 100,000-card target requires a backend database and server-side uniqueness checks. This project does not include accounts, live multiplayer, payments, wagering, cash prizes, or a production anti-cheat system. Points have no cash value.
